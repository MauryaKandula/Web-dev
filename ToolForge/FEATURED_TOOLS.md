# ToolForge featured tools

These are five first-party tools included in the ToolForge application. Each card opens its in-app tool page. They are presented by feature, not by fabricated sales or rating totals.

## 1. RepoLens — Codebase onboarding

Explore the included sample structure or upload a local text manifest to map folders, infer likely technologies, and draft a first-run setup guide. RepoLens does not fetch a GitHub URL in this preview.

Source: [RepoLensPage.tsx](src/client/pages/RepoLensPage.tsx)  
Test suite: [repolens.test.ts](src/tests/repolens.test.ts)

## 2. InterviewLab — DSA practice

Work through data structures and algorithms by topic, use the built-in practice workflow, and review progress in one place. Designed for interview preparation and structured practice.

Source: [InterviewLabPage.tsx](src/client/pages/InterviewLabPage.tsx)  
Test suite: [interviewlab.test.ts](src/tests/interviewlab.test.ts)

## 3. PlacementForge — Resume and job-fit workspace

Shape a developer resume around a specific job description, review keyword coverage, and prepare a polished application copy. It complements, rather than replaces, a candidate’s own review of their application.

Source: [PlacementForgePage.tsx](src/client/pages/PlacementForgePage.tsx)  
Test suite: [placementforge.test.ts](src/tests/placementforge.test.ts)

## 4. PortfolioDeploy — Portfolio builder

Choose projects, organize their descriptions, and export a static portfolio bundle designed for GitHub Pages or another static host.

Source: [PortfolioDeployPage.tsx](src/client/pages/PortfolioDeployPage.tsx)  
Test suite: [portfoliodeploy.test.ts](src/tests/portfoliodeploy.test.ts)

## 5. FreelanceOS — Client work organizer

Draft a project proposal, break work into milestones, and prepare invoice details for freelance engagements.

Source: [FreelanceOSPage.tsx](src/client/pages/FreelanceOSPage.tsx)  
Test suite: [freelanceos.test.ts](src/tests/freelanceos.test.ts)

## Status

These tools are part of the local ToolForge app. This page does not claim a public launch, sales history, customer ratings, or a production service-level guarantee. Razorpay payments remain unavailable until merchant test credentials are configured; creator payouts and recurring memberships are not implemented.
