# Third-party notices

ToolForge depends on third-party packages listed in package.json and locked in package-lock.json. Review each package’s license in the corresponding npm package metadata before redistributing a bundled build.

The application source uses React, Express, Vite, TypeScript, Tailwind CSS, Vitest, bcryptjs, cors, dotenv, jsonwebtoken, lucide-react, uuid, and Node.js built-in modules.

The local repositories/ directory is excluded from this publication. Its upstream code and licenses have not been reviewed for redistribution.
